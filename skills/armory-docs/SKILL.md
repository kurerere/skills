# 本地手册检索

此技能只提供检索流程，不附带产品手册。手册数据放在技能安装目录之外，避免更新技能时覆盖资料。

数据根目录使用 `AGENTS_SKILL_DATA_DIR`，未设置时为 `~/.agents/skill-data`。
本技能的资料目录为 `<DATA_ROOT>/armory-docs/references`。

1. 先确认资料目录存在。不存在时说明手册尚未配置；用户已有资料可整理到该目录，不能捏造切片或把其他版本当作当前手册。
2. 通过 `references/sitemap.md` 或在资料目录内用 `rg` 搜索接口、命令或问题关键词。
3. 只读取命中的章节，按原手册保留参数、返回值、版本、限制和示例。注明来源章节及资料版本，未知版本明确说明。
4. 本地资料没有覆盖时，可使用用户已有的 RAG MCP 查询对应知识库，或查对应产品官方文档。说明查到的内容与当前环境之间的适用边界；没有依据的部分保留为未知。

不要从知识库或网络批量复制整本手册到公开技能仓库。更新手册数据和更新技能分别进行，资料保留原作者与许可信息。
