# 中文技术文档语域规则

## 句法

- 主语明确，能用"本设备""该目录"就不用"我们"。
- 步骤句以动词开头：配置…… / 执行…… / 校验……；不写"接下来我们需要配置……"。
- 一句一层逻辑。并列超过三项改用列表或表格。
- 结论前置：段首句是结论，后文是支撑。

## 禁用词（口语、情绪、自评）

坑、踩坑、挂死、跑不通、打通、搞、弄、搞定、弄好、一下、其实、很、非常、完美、彻底解决、众所周知、显然、不用说、顺手、基本能用、应该没问题、大概。

## 替换表

| 口语 | 书面 |
| --- | --- |
| 搞 / 弄 | 配置、安装、执行、修改（按动作选） |
| 跑不通 | 执行失败、无法启动 |
| 挂死 / 卡住 | 进程无响应、调用未返回 |
| 打通 | 完成端到端验证、链路可用 |
| 踩坑 | 常见错误 |
| 一下 | （删除） |
| 我试了 / 我验证过 | 已验证 / 实测通过 |
| 装一下 | 安装 |
| 建议你先 | 第一步应 |
| 需要注意的是 | 删；确有风险时改为"注意：" |

## 慎用词

可能、通常、一般、建议、尽量、适当、若干。这些词在没有边界条件时等于没写；若必须用，补上条件：在（条件）下可能……。

## 段落

- 段落 2 到 5 句。超过 5 句拆开，少于 2 句考虑并入。
- 不用"首先/其次/最后"三段式承载内容。
- 每节末尾不加空洞小结。
- 开头不写背景铺垫。第一句就是读者需要的第一条信息。

## 语气

- 陈述句为主，不评价、不感叹、不自夸。
- 不确定就标注档位，不用模糊词遮盖。
- 对读者的称呼统一为"读者"或省略；不写"你会发现""你只需要"。

## 格式

- 中文正文用全角标点，代码与路径用半角。
- 命令块标注语言，一行一条可执行命令。
- 强调只用于风险与版本约束，全文加粗不超过 10 处。

## 英文文档

同样适用：主动语态、动词开头、无铺垫、无自评、结论前置。避免 It is important to note that、In today's fast-paced world、delve into、seamless、robust。
