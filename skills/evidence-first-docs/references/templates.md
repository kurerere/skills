# 文档骨架模板

骨架按读者动作排序，不按知识点排序。选用后检查：任意删掉一章，后续章节是否失效。

## 操作手册 / 教程

1. 适用范围（机型、系统、版本、前置条件）
2. 部署步骤（每步：命令 + 期望输出）
3. 创建或执行（配置全文内嵌，供复制）
4. 验证（可观测证据：设备、环境变量、进程、返回码）
5. 使用说明（参数、多实例、限制）
6. 备选方案（场景分叉时）
7. 常见问题（现象 → 原因 → 处理）
8. 回退（变更项 → 回退方式 → 备份位置）

## 验证报告

1. 结论（一页内：通过或不通过，附关键数字）
2. 验证范围（对象、版本、环境、约束）
3. 验证项与结果（表：项 / 方法 / 期望 / 实测 / 结论）
4. 异常与根因
5. 未覆盖项与风险
6. 附件索引

## 技术方案 / 设计文档

1. 结论与建议（先给选择）
2. 硬约束（版本边界、硬件限制、既有配置）
3. 现状
4. 方案（含被否决的备选及否决原因）
5. 实施步骤与风险
6. 回退
7. 待确认

## 故障复盘

1. 影响与时间线
2. 直接原因
3. 根本原因
4. 处置与恢复
5. 改进项（负责人、期限）
6. 同类风险排查

## 接口 / 使用说明

1. 用途与边界
2. 快速开始（最短可用路径）
3. 参数表（名称 / 类型 / 默认值 / 必填 / 说明）
4. 返回与错误码
5. 示例
6. 限制

## 对外交付说明 / 汇报

1. 交付内容
2. 使用条件与环境要求
3. 已知限制
4. 支持方式
