# 交付自查

按本次文档的用途核对，不适用的项跳过，不为完成清单扩写。

- **事实与判断**：正文与来源一致吗？是否把观察写成原因、把估算写成结果，或把设计目标写成现有能力？版本和条件是否足以判断适用范围？
- **读者路径**：操作者能找到前提、步骤和判定吗？评审者能理解依据与代价吗？接口调用者能处理失败吗？
- **限制与未知项**：关键边界、未验证内容和已知问题是否说清？信息不足时是否保留未知，而非补出看似完整的答案？
- **操作影响**：有副作用的步骤是否明确目标、影响和恢复办法？没有恢复办法的是否如实说明？是否为写文档执行了未授权的操作？
- **内容取舍**：删减是否丢掉必要背景、决策理由或行为约定？是否重复了权威文档或代码可查的细节？
- **可读性**：术语、示例和数据是否前后一致？是否有空泛评价、碎句、重复总结或让读者猜条件的省略？

已安装 `writing` 时可按需使用其扫描脚本辅助复查。命中只是提示；工具未运行或失败时，不把它写成检查通过。
