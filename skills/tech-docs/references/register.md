# 组织与示例

根据读者需要选择表达方式。连续解释用段落，并列比较用表格，顺序操作用步骤；图能更清楚地呈现关系或状态时再画。标题帮助定位内容，不固定动宾句式。

## 命令和配置

给出完成当前步骤所需的最小完整调用，说明执行位置、依赖、可变参数从哪里获取，以及怎样判断结果。敏感值用明确的占位符，不放真实凭据。

已存在且可访问的脚本或配置可以链接并解释用法，不必全文复制。需要内嵌片段时避免省略影响执行的部分；可移植示例允许占位，但要标明替换方法。项目已有的自动生成接口定义和字段表优先作为权威来源。

## 示例与术语

示例服务于解释，不证明目标环境已经验证。观测输出、构造示例和预期结果标清区别；复用示例时核对前后数字、条件、接口及路径是否一致。

同一概念沿用同一叫法；有不同含义的术语说明差别。缩写是否展开由读者背景决定。排版和语言沿用项目约定，不机械替换准确术语。
