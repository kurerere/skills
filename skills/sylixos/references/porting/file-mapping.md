# 文件映射与文件写入的一致性

文件内容正确但 mmap 视图陈旧，或数据库出现页元数据异常时读取。匿名堆页回收另见 [memory-reclaim.md](memory-reclaim.md)。

## 问题与现象

历史移植中出现过：建立只读 MAP_SHARED 映射并读入某页后，用 pwrite 修改同一页，文件读取已得到新内容，原映射仍返回旧内容；新建映射可以读到新内容。依赖映射读取元数据的数据库可能因此报页状态错误。

## 当时的处理思路

文件读取改为按需 pread 加页缓存，写入后使相关缓存失效；也保留过堆缓冲、写入后 msync(MS_INVALIDATE) 的方案。它们用于绕过既有映射不刷新的问题，没有修复内核本身。

后续项目根据当前内核、文件系统和数据访问方式选择实现，并验证写后读取与持久化行为。重新映射也不一定安全，同样需要验证。
