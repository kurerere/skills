# V8 平台层与内存

只用于当前项目确实包含 V8 的情况。宏、平台文件和内存布局随 V8 版本变化，历史配置不能直接复制。

## 平台层

检查该版本的平台选择、页大小、时间、虚拟内存和采样机制是否满足 SylixOS 目标需求。旧适配使用过 V8_OS_SYLIXOS 和独立平台文件；当前版本可能有不同入口。根据实际接口实现并测试，缺少采样设施时说明功能限制。

## ARM64 JIT 与地址范围

遇到 CodeRange 预留失败或生成代码跳转异常时，先收集分配失败、地址布局、实际分支指令和调用跳板证据。并非所有 ARM64 跳转都使用相同范围，不能仅凭异常 PC 或地址距离确认根因。

历史配置使用过 16 MB CodeRange、3 MB 最小值及 8 MB SegmentedTable 预留。这些不是通用默认值，当时的页大小、表结构、沙箱/指针压缩配置和工作负载都没有记录，不要直接套用。

从当前 V8 的分配策略、地址约束与目标内存限制推导配置。验证启动、实际启用的 JIT 路径、代码增长、表容量和内存压力；smoke test 通过不证明较大工作负载安全。保留项目要求的特性，必要的降级明确说明并验证。
