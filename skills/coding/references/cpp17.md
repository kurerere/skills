# C++17

- 以实际构建配置和目标标准库为准。示例和新增代码限定在 C++17 可用的语言与库能力内。
- 用 RAII 表达资源释放。优先使用具有值语义的标准类型和现有资源包装。独占所有权明确交给值或 `std::unique_ptr`，只有多个持有者确实共享生命周期时才使用 `std::shared_ptr`。
- 将指针、引用、迭代器和 `std::string_view` 当作借用。核对底层对象在返回、存储或异步调用后是否仍然存活，以及移动和容器变更是否会使借用失效。
- 保持项目既有异常策略。对状态更新先构造并验证候选结果，按契约一次提交。构造或后续步骤可能失败时，核对资源释放及对象有效状态。
- 优先复用标准容器、算法和普通函数。接口需要表达可缺失的值时，考虑项目已有类型或 `std::optional`。引入模板或动态多态前，确认具体复用场景和调用契约。
- 纯重构用现有构建目标和测试建立绿灯基线。若移动资源管理代码，验证成功和失败路径上的所有权移交、清理时机及已有调用者行为。
